This module allows the user to keep track of the different revisions
of a quotation.

When a quotation is in the *Cancelled* or *Sent* state, the user can
create a new revision via the *New Revision of Quotation* button. The
previous revision is archived (set inactive) and its state is set to
*Cancelled*. The new revision receives a suffix `-NN` appended to the
original order reference.

The form view shows a *Prev. revisions* smart button listing all
archived revisions, and a *Current Revision* smart button (visible on
archived revisions) to navigate back to the active revision.
